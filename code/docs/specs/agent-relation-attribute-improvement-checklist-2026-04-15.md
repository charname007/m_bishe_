# Agent 关系与属性体系改进清单（2026-04-15）

适用范围：
- `agent/agents/schemas.py`
- `agent/agents/prompts.py`
- `agent/agents/nodes.py`
- `agent/agents/workflow.py`
- `agent/tests/`

---

## 0. 现状与问题（基于 `agent/tests/full_workflow_result.json`）

- 样本规模：50 条语料，192 条三元组。
- 关系覆盖不均衡：`方向/穿过/劣于` 出现为 0，`承载活动` 占比偏高。
- RE 属性键存在漂移：出现 `活动/事件内容/距离` 等非标准键，且有 `str` 直接写入 `attributes` 的情况。
- 代码中定义了完整标准属性体系，但当前主要依赖提示词约束，缺少强校验与规范化落地。
- Label 输出的关系属性字段与聚合阶段读取口径不一致（存在“写 A 读 B”的风险）。

---

## 1. 本次改造目标

- 目标 G1：RE/Joint 输出属性键标准化率达到 100%（仅允许标准键集合）。
- 目标 G2：三元组 `attributes` 结构化率达到 100%（禁止 `str/list` 直接顶层写入）。
- 目标 G3：关系属性在聚合阶段可稳定继承，不再出现字段丢失。
- 目标 G4：新增校验后，错误可观测（日志可追踪、测试可复现）。

---

## 2. P0（本周，必须完成）

### P0-1 属性键标准化与别名映射
- [ ] 在 `schemas.py` 增加“关系 -> 合法属性键集合”常量（单一真值源）。
- [ ] 在 `nodes.py` 增加 `normalize_triple_attributes()`：
  - 将别名键映射到标准键（例如 `距离 -> 距离值`）。
  - 非法键进入 `_attr_warnings` 或日志，不直接丢弃（先可观测后收敛）。
- [ ] 在 `create_re_node` 与 `create_joint_ner_re_node` 后统一调用该规范化函数。

验收标准：
- [ ] 任意三元组的 `attributes` 最终均为 `dict`。
- [ ] 属性键仅出现在标准集合中或被记录为 warning。

---

### P0-2 关系-属性白名单校验
- [ ] 在 `nodes.py` 增加 `validate_relation_attributes(relation, attrs)`。
- [ ] 只允许“关系对应的属性键”通过；不匹配时记录 issue 并标记低置信度。
- [ ] 在评估/自检阶段增加该规则结果输出，便于排查。

验收标准：
- [ ] 对每条三元组可输出“属性是否合法”的判定结果。
- [ ] 非法组合不会静默通过。

---

### P0-3 修复 Label 与聚合口径不一致
- [ ] 对齐 `LabelResult.relations` 的字段语义与聚合读取逻辑。
- [ ] 在 `aggregator_node` 内移除对无效键（如 `类型/细分`）的依赖，改为读取真实关系属性字段。
- [ ] 保证 `relation_attrs` 可被完整合并到最终三元组/落库对象。

验收标准：
- [ ] Label 产出的关系属性在聚合结果中可追踪到。
- [ ] 不再出现“Label 有值但聚合为空”的系统性丢失。

---

### P0-4 测试补齐（防回归）
- [ ] `test_nodes.py`：新增属性标准化与白名单校验测试（含反例）。
- [ ] `test_workflow.py`：新增端到端断言，验证 `attributes` 结构与键合法性。
- [ ] 加入 3 类固定样本：空间关系、活动关系、事件关系。

验收标准：
- [ ] 新增测试可稳定复现并覆盖核心校验路径。
- [ ] CI/本地测试通过。

## 3. P1（下周，建议完成）

### P1-1 将 `attributes` 从弱类型升级为强类型
- [ ] 将当前 `Dict[str, Any]` 升级为按关系类型区分的结构（discriminated union 或分关系模型）。
- [ ] 在解析阶段直接失败非法结构，减少后处理补救成本。

验收标准：
- [ ] 模型层可直接拒绝不合法属性结构。
- [ ] 提示词错误输出能够在解析期暴露。

---

### P1-2 建立实体类型 × 关系类型兼容矩阵
- [ ] 在 `rule_based_validation` 增加实体类型约束（如 `穿过` 更偏向道路头实体）。
- [ ] 将校验结果回写三元组（`_rule_valid`, `_rule_issues`）。

验收标准：
- [ ] 不合理三元组（类型不兼容）可被稳定拦截。
- [ ] 规则误杀率可量化（通过测试样本统计）。

---

### P1-3 提示词与示例统一收敛
- [ ] 对 `RE_PROMPT / JOINT_NER_RE_PROMPT / BATCH_JOINT_PROMPT` 使用同一套属性键词典。
- [ ] 示例中不再出现非标准键，避免“训练反例”。

验收标准：
- [ ] 三套提示词中的属性示例完全一致。
- [ ] 新跑样本中“非标准键”占比明显下降。
