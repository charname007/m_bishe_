Delaunay三角剖分：端点为由提供的点集组成，任何三角形的外接圆不包含其他的点




1. **点化（Pointification）**：Delaunay 算法只能处理点。所以我们需要提取 POI 的坐标，以及建筑物（面）、街区（面）、道路（线）的**质心（Centroid）**。
    
2. **统一 ID**：为了防止不同 SHP 文件的 ID 冲突，我们给每个实体生成全局唯一 ID（如 POI_1, BLD_2）。
    
3. **构建三角网**：将所有实体的质心合并为一个坐标集合，投入 scipy.spatial.Delaunay 计算。
    
4. **提取边并过滤**：从生成的三角形中提取三条边。**（关键点：Delaunay 会把最外围相距很远的散点也连起来，我们需要加一个距离阈值，剔除过长的“假邻接”边）**。
    
5. **入库 Neo4j**：将实体作为节点（Nodes），将合法的连线作为关系（NEAR_TO）写入图数据库。
