### C++ 语言读取方式（推荐推荐）

C++ 推荐直接使用 std::string，比 C 语言的字符数组更安全、更方便。

#### 1. 读取单个单词 / 不含空格的字符串

如果输入的字符串**没有空格**（以空格或回车结束），直接用 cin。

codeC++

```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    // 读取单个字符串，遇到空格或回车停止
    cin >> s; 
    
    // 多组测试用例循环读取模板：
    while (cin >> s) {
        cout << s << endl;
    }
    return 0;
}
```

特点：cin >> 会自动跳过开头的空格和回车，非常省心。

#### 2. 读取一整行 / 包含空格的字符串

如果输入是一句话（如 "hello world"），需要连空格一起读入，使用 getline。

codeC++

```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    // 读取一整行，直到遇到回车才停止
    getline(cin, s);
    
    // 多组测试用例循环读取模板：
    while (getline(cin, s)) {
        cout << s << endl;
    }
    return 0;
}
```

#### 3. 读取单个字符 (char)

codeC++

```
char c;
cin >> c; // 会自动跳过空格和回车
```


###  机试最高频踩坑点（必看）

在机试中，**“回车符残留”** 是导致读取出错的第一大元凶。

**场景**：先输入一个数字（或者不含空格的字符串），然后输入一个带空格的字符串。

codeText

```
输入样例：
5
hello world
```

**错误代码：**

codeC++

```
int n;
string s;
cin >> n;         // 读走了 5，但把回车 '\n' 留在了缓冲区
getline(cin, s);  // getline 瞬间读到了刚才留下的 '\n'，直接结束，s 变成空串！
```

**正确解决代码（C++）：**

codeC++

```
int n;
string s;
cin >> n;
cin.ignore(); // 吞掉缓冲区留下的那个回车符
getline(cin, s);
```


### 性能优化（针对卡时间的算法题）

如果你用 C++，机试/算法题的数据量很大（超过 

```
105105
```

 级别），cin 和 cout 会比较慢，导致超时（Time Limit Exceeded）。  
可以在 main 函数的第一行加上这句**“解绑代码”**，让 cin 跑得和 scanf 一样快：

codeC++

```
int main() {
    // 解除 cin/cout 与 C语言 stdio 的绑定，提升 IO 速度
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    
    // 接下来正常用 cin 和 cout 即可
    // 注意：加了这句后，千万不要再混用 cin 和 scanf 了！
}
```
