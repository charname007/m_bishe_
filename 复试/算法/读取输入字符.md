### C++ 语言读取方式（推荐推荐）

C++ 推荐直接使用 std::string，比 C 语言的字符数组更安全、更方便。

#### 1. 读取单个单词 / 不含空格的字符串

如果输入的字符串**没有空格**（以空格或回车结束），直接用 cin。

codeC++

```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    // 读取单个字符串，遇到空格或回车停止
    cin >> s; 
    
    // 多组测试用例循环读取模板：
    while (cin >> s) {
        cout << s << endl;
    }
    return 0;
}
```

特点：cin >> 会自动跳过开头的空格和回车，非常省心。

#### 2. 读取一整行 / 包含空格的字符串

如果输入是一句话（如 "hello world"），需要连空格一起读入，使用 getline。

codeC++

```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    // 读取一整行，直到遇到回车才停止
    getline(cin, s);
    
    // 多组测试用例循环读取模板：
    while (getline(cin, s)) {
        cout << s << endl;
    }
    return 0;
}
```

#### 3. 读取单个字符 (char)

codeC++

```
char c;
cin >> c; // 会自动跳过空格和回车
```
