**原地 (O(1)) 空间求 Least Missing Number（MEX）** 是一道非常经典的算法题，核心思想可以概括成一句话：

> **把数字 i 放到下标 i 的位置上，用数组本身当哈希表。**

这样就不需要额外空间，只需要不断交换元素即可。

下面我从 **直觉 → 算法思想 → 步骤 → 示例 → 代码 → 正确性证明** 系统讲清楚。

---

# 一、问题定义

给定数组：

```
A = [3,0,1]
```

求：

```
最小没有出现的非负整数
```

也就是

```
MEX
```

---

# 二、关键观察（算法灵魂）

如果数组长度为 **n**

那么：

```
mex ∈ [0, n]
```

因为：

```
n 个数最多包含
0 1 2 ... n-1
```

如果都存在：

```
mex = n
```

否则：

```
mex = 第一个缺失的 i
```

---

# 三、核心思想：下标哈希（Index Hashing）

目标状态：

```
index : 0 1 2 3
value : 0 1 2 3
```

也就是说：

```
值 i 应该放在位置 i
```

如果数组能整理成这样：

```
[0,1,2,?,...]
```

那么：

```
第一个 a[i] ≠ i
就是 mex
```

---

# 四、如何整理数组？

策略：

如果当前元素

```
a[i] = x
```

并且

```
0 ≤ x < n
```

那么它应该在：

```
index = x
```

位置。

于是：

```
swap(a[i], a[x])
```

直到它被放对位置。

---

# 五、完整算法步骤

假设数组长度 **n**

### Step1：遍历数组

```
for i in [0,n)
```

不断交换：

```
while a[i] 在合法范围 且 a[i] 没放对
    swap
```

条件：

```
0 ≤ a[i] < n
且
a[i] ≠ a[a[i]]
```

---

### Step2：再次扫描

```
for i in [0,n)
    if a[i] != i
        return i
```

---

### Step3：如果都正确

```
return n
```

---

# 六、完整代码（C++）

```cpp
int mex(vector<int>& a) {
    int n = a.size();

    for (int i = 0; i < n; i++) {

        while (a[i] >= 0 && a[i] < n && a[i] != a[a[i]]) {
            swap(a[i], a[a[i]]);
        }

    }

    for (int i = 0; i < n; i++) {
        if (a[i] != i)
            return i;
    }

    return n;
}
```

复杂度：

```
时间 O(n)
空间 O(1)
```

# 七、完整运行示例

数组：

```
[3,0,1]
```

n=3

---

## 第一步 i=0

```
a = [3,0,1]
```

a[0] = 3

```
3 ≥ n
```

不处理。

---

## 第二步 i=1

```
a = [3,0,1]
```

a[1] = 0

应该在

```
index = 0
```

交换：

```
swap(a[1],a[0])
```

变成：

```
[0,3,1]
```

继续检查：

```
a[1] = 3
3 ≥ n
```

停止。

---

## 第三步 i=2

```
a = [0,3,1]
```

a[2] = 1

应该在：

```
index = 1
```

交换：

```
swap(a[2],a[1])
```

得到：

```
[0,1,3]
```

---

# 八、数组整理完成

最终：

```
[0,1,3]
```

检查：

```
index 0 → 0 ✓
index 1 → 1 ✓
index 2 → 3 ✗
```

所以：

```
mex = 2
```

---

# 九、为什么时间是 O(n)

关键点：

**每个元素最多交换一次到正确位置。**

因为：

```
swap(a[i], a[a[i]])
```

会让至少一个元素进入正确位置。

所以：

```
最多 n 次交换
```

因此：

```
时间 O(n)
```

---

# 十、为什么不会死循环

因为有这个条件：

```
a[i] != a[a[i]]
```

例如：

```
[1,1]
```

如果没有这个条件：

```
swap(a[0],a[1])
swap(a[1],a[1])
swap(a[1],a[1])
...
```

会死循环。

加入判断就避免了。

# 十二、面试官最爱问的追问

### 1 为什么 mex ≤ n

因为：

```
n 个数
最多覆盖 0..n-1
```

---

### 2 为什么能 O(n)

因为：

```
每次 swap
至少一个元素归位
```

---

### 3 为什么 O(1) 空间

因为：

```
直接修改原数组
```

数组充当：

```
哈希表
```
