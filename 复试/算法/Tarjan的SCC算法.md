在图论中，**SCC（Strongly Connected Component，强连通分量）**是复试和机试中非常常见的算法考点。  
其中最经典的算法之一就是 **Tarjan算法**。它的核心思想可以理解为：

> **用一次 DFS 遍历，在搜索过程中动态判断哪些节点属于同一个强连通分量。**

时间复杂度：**O(V + E)**。

我给你按照 **复试常见的理解路径**讲清楚：

---

# 一、什么是强连通分量（SCC）

在**有向图**中：

如果一组节点满足：

- 任意两个节点 **u → v 可达**
    
- 同时 **v → u 也可达**
    

那么这组节点构成一个 **强连通分量**。

例如：

```
1 → 2 → 3
↑   ↓   ↓
6 ← 5 ← 4
```

这里：

```
{1,2,3,4,5,6}
```

整体就是一个 SCC，因为任意节点都能互相到达。

再看一个例子：

```
1 → 2 → 3 → 4
    ↑   ↓
    6 ← 5
```

SCC：

```
{2,3,5,6}
{1}
{4}
```

---

# 二、Tarjan算法的核心思想

Tarjan算法本质是：

**DFS + 栈 + 时间戳**

在 DFS 过程中维护两个重要数组：

### 1️⃣ dfn[u]

表示：

```
节点 u 第一次被 DFS 访问的时间
```

例如：

```
dfn[u] = 1,2,3,4...
```

---

### 2️⃣ low[u]

表示：

```
u 及其子树
能够回到的最早祖先的 dfn
```

公式：

```
low[u] = min(
    dfn[u],
    dfn[v] (通过返祖边),
    low[child]
)
```

---

# 三、Tarjan算法最关键的判断

当出现：

```
dfn[u] == low[u]
```

说明：

> **u 是一个 SCC 的根节点**

此时：

从栈顶不断弹出节点，直到 u 为止  
这些节点就构成 **一个强连通分量**

---

# 四、Tarjan算法流程

步骤如下：

### Step1：初始化

```
dfn[u] = 0
low[u] = 0
栈 stack
时间戳 time = 0
```

---

### Step2：DFS访问节点 u

```
dfn[u] = low[u] = ++time
u 入栈
```

---

### Step3：遍历邻接点 v

情况1：v 未访问

```
tarjan(v)
low[u] = min(low[u], low[v])
```

---

情况2：v 已访问且在栈中

说明存在 **回边**

```
low[u] = min(low[u], dfn[v])
```

注意：

只对 **栈中的节点更新**。

---

### Step4：判断是否形成 SCC

如果：

```
dfn[u] == low[u]
```

则：

```
u 是 SCC 根
```

不断弹栈：

```
while (stack.top != u)
    pop
pop(u)
```

这些节点属于一个 SCC。

---

# 五、Tarjan算法示例

图：

```
1 → 2 → 3 → 1
3 → 4 → 5 → 4
```

真实 SCC：

```
{1,2,3}
{4,5}
```

DFS过程：

```
1
 └─2
    └─3
       ├─1 (回边)
       └─4
          └─5
             └─4
```

当：

```
dfn[4] == low[4]
```

弹出：

```
5
4
```

形成：

```
{4,5}
```

继续回溯：

当：

```
dfn[1] == low[1]
```

弹出：

```
3
2
1
```

形成：

```
{1,2,3}
```

# 六、Tarjan算法代码（机试模板）

这是最经典模板：

```cpp
const int N = 100005;

vector<int> g[N];

int dfn[N], low[N];
bool inStack[N];

stack<int> st;

int timer = 0;
int scc_cnt = 0;

void tarjan(int u)
{
    dfn[u] = low[u] = ++timer;

    st.push(u);
    inStack[u] = true;

    for(int v : g[u])
    {
        if(!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        }
        else if(inStack[v])
        {
            low[u] = min(low[u], dfn[v]);
        }
    }

    if(dfn[u] == low[u])
    {
        scc_cnt++;

        while(true)
        {
            int x = st.top();
            st.pop();

            inStack[x] = false;

            if(x == u) break;
        }
    }
}
```

复杂度：

```
时间：O(V + E)
空间：O(V)
```

# 七、Tarjan算法为什么正确（复试常问）

核心逻辑：

### low[u] 表示

```
从 u 出发
能回到的最早祖先
```

如果：

```
low[u] == dfn[u]
```

说明：

```
u 及其子树
无法回到 u 之前的节点
```

因此：

```
u 是一个 SCC 的根
```

而栈中从 u 之后加入的节点：

```
都可以回到 u
```

所以构成 **一个强连通分量**。

---

# 八、Tarjan算法的直观理解（非常关键）

想象 DFS 是一条探险绳索：

```
DFS树 = 向前探索
回边 = 能回到过去
```

如果某个点：

```
无法回到更早的祖先
```

说明：

```
这一段 DFS 路径
形成了一个闭环区域
```

这个闭环就是 **SCC**。

栈记录：

```
当前 DFS 路径上的节点
```

当发现 **闭环结束** 时：

直接把这一段路径全部弹出。

---

# 九、复试最常问的几个问题

### 1 Tarjan为什么只需要一次DFS

因为：

```
low值在DFS回溯时更新
```

所以：

```
SCC在回溯阶段直接确定
```

不需要像 **Kosaraju算法** 那样跑两次 DFS。

---

### 2 为什么只更新栈中的节点

如果节点已经出栈：

说明：

```
该节点已经属于某个SCC
```

不能再影响当前 SCC。

---

### 3 Tarjan算法还能做什么

Tarjan思想不仅能找 SCC，还能找：

- 割点
    
- 桥
    
- 双连通分量
    

都是 **DFS + low 数组**。
