## 1. 核心规则（针对 `||` 操作符）

对于 $B \rightarrow B_1 \ || \ M \ B_2$：

- **$B_1.falselist$**：回填为 $M.instr$（即 $B_2$ 的第一条指令地址）。
    
- **$B.truelist$**：等于 $merge(B_1.truelist, B_2.truelist)$。
    
- **$B.falselist$**：等于 $B_2.falselist$。
    

## 2. 分步推导

假设起始地址为 **100**。

#### 第一步：处理 `a == b` (记为 $B_{sub1}$)

100: `if a == b goto _` (写入 `truelist`)

101: `goto _` (写入 `falselist`)

- **$B_{sub1}.truelist = \{100\}$**
    
- **$B_{sub1}.falselist = \{101\}$**
    

#### 第二步：中间标记 $M_1$

$M_1.instr = 102$（即下一条指令的地址）。

根据 `||` 规则，我们需要把 $B_{sub1}.falselist$（即地址 101）回填为 102。

> **回填后：** 101: `goto 102`

#### 第三步：处理 `c == d` (记为 $B_{sub2}$)

102: `if c == d goto _`

103: `goto _`

- **$B_{sub2}.truelist = \{102\}$**
    
- **$B_{sub2}.falselist = \{103\}$**
    

#### 第四步：计算 `(a==b || c==d)` (记为 $B_{left}$)

- **$B_{left}.truelist = merge(B_{sub1}.truelist, B_{sub2}.truelist) = \{100, 102\}$**
    
- **$B_{left}.falselist = B_{sub2}.falselist = \{103\}$**
    

#### 第五步：中间标记 $M_2$

$M_2.instr = 104$。

根据 `||` 规则，将 $B_{left}.falselist$（即地址 103）回填为 104。

> **回填后：** 103: `goto 104`

#### 第六步：处理 `e == f` (记为 $B_{sub3}$)

104: `if e == f goto _`

105: `goto _`

- **$B_{sub3}.truelist = \{104\}$**
    
- **$B_{sub3}.falselist = \{105\}$**
    

---

## 3. 最终结果汇总

|**子表达式**|**truelist**|**falselist**|
|---|---|---|
|`a == b`|{100}|{101}|
|`c == d`|{102}|{103}|
|`(a == b \| c == d)`|{100, 102}|{103}|
|`e == f`|{104}|{105}|
|**`(a==b \| c==d) \| e==f`**|**{100, 102, 104}**|**{105}**|

## 4. 生成的三地址代码预览（回填前）

100: `if a == b goto _`

101: `goto 102` (已被回填)

102: `if c == d goto _`

103: `goto 104` (已被回填)

104: `if e == f goto _`

105: `goto _`
